## M50 v0.50.0：捕获即返回值（if / switch 的糖）
- **语法**：`if (o) v;`、`if (o) v else 0`、`switch (u) { .some: v, .none: 0 }`——
  捕获名后面紧跟 `; , ) } ] else` 时，臂值就是捕获值本身（≡ `if (o) v t: { t: v; }`）。
- **实现**：解析期展开成「捕获 + NK_IDENT(捕获名)」，复用 M19 的「捕获 + 单值臂」，
  sema/backend 零改动。两处：src/parse.c parse_if_arm(implicit_ok) + parse_switch；
  bootstrap/parse.zx 同名函数（**位置必须逐字节一致**）。
- **bool 特判**（关键，否则悄悄改掉 idiom `if (a>b) a else b`）：check_if 里条件不是
  ?T/!T 且臂就是同名 ident 时 → n->name = NULL 退回普通表达式；名字又不在作用域 →
  报 "an `if` on a bool has nothing to capture" 并把该臂按 void 算（n->b=NULL），
  避免级联 "unknown identifier"。helper: arm_is_capture_value()（块包一层也算）。
- **switch 无类型可借力**：冒号后裸名字**一定**是捕获名，`1: K,` 的值是匹配值不是常量，
  逃生口 `1: (K),`。已写进 manual §8.1 第 19 条坑（唯一影响旧代码含义的地方）。
- **顺带修自举 bug**：bootstrap/parse.zx 的 parse_dot_brace 用 self.new(NK.tuple)
  （位置=第一个元素）而非 new_at(...,t)（位置=`.{`），嵌套 `.{ .a = .{1,2} }` 会岔 3 列。
  diff_ast.sh 现在 **72/72 全等**。
- **回归**：223 项全过（新增 tests/good/if_cap_value.zx、switch_cap_value.zx；
  tests/bad/if-sugar-bool.zx、switch-cap-value-mismatch.zx）。版本 0.50.0，spec v0.28，
  decisions §83，README M50 清单+详情节，guide/manual 同步。

## M56：统一 Task——thread/fiber 收敛成一个 std.Task（未提交）
- 用户拍板：多线程/单线程/协程统一成任务接口，对外只有 std.Task；thread/fiber API 删除；同步原语独立 std.mutex/std.atomic（C 名与语义沿用 §86，运行时分开按需发射）。
- Task = 调度器调度的栈有纤程。任务签名 fn(usize)!usize（ZxErr_u64 ABI 固定）：await 带回 ret/错误 + M55 await 门直接生效 + 取消=error.cancelled 顺 !T 链冒到任务顶层、await 者收同一错误——门机制零改动换宿主长成取消模型。
- 调度器：侵入链表就绪队列 + 全局 SRWLOCK/cond + N 工作线程（默认 CPU-1，Win GetActiveProcessorCount / POSIX sysconf）；Task.init(0)=纯单线程（主线程 await 跑 run_until 推进）。任务内 await 真挂起（等待者链，finish 整体重新入队）；未开始即取消的由取出方 finish(cancelled) 结算。
- 任务完成即回收栈（DeleteFiber/free stk）——修掉 M54 纤程栈终身泄漏。
- sema：BI_TASK/BI_TASK_FN/BI_SYNC/BI_SYNC_FN；ns_member 用 ns->name 拼键两命名空间一分支；"await" 非保留字可作成员名。
- backend：emit_task_runtime（cap 环+调度器+任务）与 emit_sync_runtime 分开；缩进 static 连 forward declaration 都要（头文件组装器提升列首定义）。
- 已知取舍：全局调度锁 await 高频竞争（per-task futex/工作窃取是后续）；cancel 队列中任务不做出队摘除；scan_task_use 认 std.Task 形状、别名认不出。
