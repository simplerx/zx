## §162 语言级向量类型 @Vec(T, N)（2026-11-14）

- 用户：先「新建 向量类型 @//vec/」，澄清后选「语言级 @Vector(T,N) 内建」，再定名「@ Vec」→ 落地 **`@Vec`**。
- 定位：**类型内建**，只存在于类型位置/类型值，不占 §10 那九个值内建的名额、不进 `check_builtin`。
- 落到 clang/gcc 的 `vector_size` 类型（`typedef float ZxVec_vf32_4 __attribute__((vector_size(16)));`），不是 struct 模拟——struct 在 -O0 下完全不会产生向量指令。对齐 = 大小，与 C 侧同一个数。
- **splat 就是转换 `(@Vec(T,N))x`**：C 的 vector_size 类型不接受标量 cast（clang 报 invalid conversion），后端发 `zx_splat_vf32_4(x)` 助手（实参只求值一次）。向量之间只允许同大小重解释。
- 挡住 `/`（整数向量）、比较、位运算：C 里分别是不存在/得到逐分量掩码向量，放行会在 B1001 那层才炸。
- 自举：`NodeKind` 末尾加 `NK_VEC_TYPE`、`astload.c` 上界、`bootstrap/parse.zx` 的 `vec` 与 **值位置入口**。第一版只改类型位置，`const V4 = @Vec(f32, 4);` 报 E0300「unknown builtin @Vec」——别名/泛型实参都写在值位置，两处都得接。
- `{}` 打印：`any_desc` 给 TY_VEC 造 AK_STRUCT 描述符（N 个分量、偏移手算，没有 offsetof），否则任何向量都打成 `void`。
- 版本升 **1.4.0**（四处：zxc.h / reference 头 / manual 落款 / README 文档表）。
- 守门：`tests/good/vec.zx`、`tests/bad/vec-{length,elem,mismatch,intdiv,index,cast,op}.zx`、`test.sh §162` 三条（vector_size + 双前端一致 + dev/release 一致）、`lsptest` 的 `completion.vec.partialAtIsBuiltin`。
