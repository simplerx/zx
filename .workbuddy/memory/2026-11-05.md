3. **fs 批量 + 并发**：readAll/writeAll/appendAll 转发 std.file；编译器魔法种子从只种 std 扩到每个模块作用域（sema.c module_load_full，同名声明优先）。并发安全实测：独立 FILE*，4 路 checksum 一致，2.4x 加速（16MB）。
- 回归 236 passed / 0 failed（新增 arenaalloc/externcb/fsbatch 三个用例）。
- Zx 回调签名 fn(*const u8,*const u8)i32 与 C 的 const void* 文本不匹配是设计边界：靠 (void*) 中转，C 侧按 Zx 签名解引用。WIN32 FindData 类布局手工对齐模式见 fs.zx 顶部注释。
- 测试里 Task fn 签名是 fn(usize) !usize（错误联合），await 返回 ?usize 用 if 解包。

## FFI 补全（M24 后半）：extern struct / extern var / @link
1. **extern struct / extern union**：`const Vec3 = extern struct { … };`——类型前缀（parse_type_prefix + parse_primary 类型即值入口），is_extern 落节点、AST flg 位 2 序列化。sema `check_c_able` 逐字段校验：`?T`（带标签 optional）`[]T` `!T` 元组 方法 静态成员 默认值 全拒；`[N]T`（写作 `*[N]T`）展开成 C 内联数组 `char name[64]`（ty.c 的 ext_array_field 让 @sizeOf/@offsetOf 按内联算——普通 Zx 结构体的 *[N]T 仍是 8 字节指针，别动全局 ty_size 否则结构体拷贝按错大小 memcpy）。嵌套聚合必须也是 extern。fn 指针字段直接可用。实测 kernel32 GetLocalTime 年月日正确。
2. **@link("ws2_32")**：check_builtin 收集（zxc.c g_link_libs 去重），build_program 链接命令逐个转 -l<name>，带 / \ . 的按文件路径原样传（**手写 .o 也能挂**——混合编程验证过）。库列表盖章到 <stem>.libs，变了强制重链（.flags 盖不住链接级差异）。
3. **extern var**：`extern var g_counter: i32;`——ensure_raw 早退分支（g_fn_depth>0 拒、非 var 拒、无标注拒、有初值拒），cname 用原名（sema_sym_is_extern 扩到 NK_DECL），gen_global 发 `extern T name;` 不定义存储。**坑：backend 全局发射循环 `if (!it->b) continue;` 会把无初值的 extern var 挡掉**（已加 is_extern 旁路）；未被引用的声明不发射（惰性检查），所以纯声明测试不会产生 undefined symbol。
4. **@offsetOf** 补了 sema 侧实现（backend 早就有 case，T,T 布局在 ty_size 里顺带算好）。
5. **bootstrap 是真实前端**：zxc 的 .zx 解析走 zxfe.exe 子进程（bootstrap/lex.zx+parse.zx），改语法必须镜像过去——本次在 C parse.c 加了 case 却不生效排查了半小时才发现。AST 写端 zxfe.zx 已统一序列化 is_extern（flg 位 2），装载端 astload.c 已读，两端零改动。
6. 回归 247 passed / 0 failed（新增 exstruct/exlink/exvar 三个 good + 六个 bad）。demo/ffi/kernel32.zx 是绑定模块模式示范。
- C 侧消息如 "only extern binding"（extern const）在真实前端到不了（bootstrap 解析层就 Fail 无消息）——bad 测试别写这种 expect。
- println 不支持 `{:0>2}` 填充格式，只有 `{}`。

## M25：extern "C" 块糖 + OpenGL 全链路（FFI 第一个真实用户）
1. **extern "C" { … } 块糖**：块内 fn → extern fn、var → extern var、const Name = struct/union → extern struct。解析器返回标记 is_extern 的 NK_BLOCK，parse_program 把块内 items 上提到文件根（两端 bootstrap/parse.zx + src/parse.c 镜像）。**pub 现在允许修饰 extern 声明**（旧限制删除）——绑定模块的 extern 就是公开 API；块内 pub 透传（parse_extern_item 递归处理）。AST 无新格式（块在解析期就摊开，序列化只见平铺声明）。
2. **OpenGL 全链路 demo（demo/ffi/）**：main.zx + user32/gdi32/opengl32 三绑定模块（module() 相对调用者文件解析）。WNDCLASSW 含函数指针字段（def_proc 包一层 Zx 回调），PIXELFORMATDESCRIPTOR 26 字段全镜像，实测打出 "NVIDIA GeForce RTX 5060 / OpenGL 4.6.0 NVIDIA 610.88"——user32→gdi32→opengl32 三层布局全对的运行时证据。
3. 踩坑实录：
   - **GL 常量抄错**：GL_VENDOR=0x1F00（不是 0x1F24！），GL_VERSION=0x1F02。glGetString(非法枚举) 返 NULL，之前 segfault 就是 cstr(NULL)——先怀疑布局、再怀疑 ABI，最后才发现是自己的常量表。
   - **管道下 stdout 全缓冲**：段错误会丢 println 输出，调试用 extern _write(1,...) 打无缓冲标点（fflush 需 FILE*，Zx 侧过不去）。
   - struct 字面量字段位不能写内建调用（@sizeOf 要先提到 let）；`(T)@expr` 转换要再包一层括号。
   - `break` 不存在；`_ = f()` 不存在；while 无 `: (incr)` 继续体（bootstrap 里全用循环体内自增）。
   - `(*u8)(0)` 造 NULL 指针可用；指针比较/`(usize)ptr` 反向转换也可用。
   - cstr 模式：extern 返回 *const u8 → `(*const [256]u8)p` 数组视图 → 扫 NUL → `buf[0..n]` 切片即可直接 println（不需要 strlen）。
4. 回归 249 passed / 0 failed（新增 exblock.zx、exblock-varinit.zx）。

## M26：`_ =` 丢弃 + @embedFile + 格式化 spec + `?*T` 无标签 optional
1. **`_ = expr`**：check_assign 顶部拦截（左值名 "_" 且无 sym），右值 void 报 E0306；后端走临时槽位 gen_value。`_ = f()` 之前不存在。
2. **@embedFile**：编译期读文件进 `n->str/n->str_len`，ct_eval 返回 val_str（R1 const 依赖），后端发 `((ZxSlice_u8){...})`。路径相对当前模块（path_dup_dir+path_join）。check_builtin 里 read_source/path_dup_dir/path_join 需前置声明。
3. **格式化 spec 补全**：`{[idx][verb]:[fill][align][width][.prec]}`。冒号分割同步进 sema 的 check_fmt_args（E0802 校验器要认得 `{:>8}`）。空格填充映射 printf 旗标（零成本）、零填充+右对齐用 '0' 旗标，自定义填充/居中走 zx_fmt_pad/zx_fmt_pads 助手（g_need_pad 条件发射，含 stdarg.h）。字符串默认左对齐、数字默认右对齐。精度上限 256。
4. **`?*T` 无标签 optional（ty_opt_flat）**：null = 0 指针，C 表示直接 `T*`，sizeof = 8（`?*i32` 16→8；自引用 `next: ?*Node` 节点不多占标签字节，Node=16）。布局全在 ty.c（ty_size + align）/backend.c（ctype/条件判定/.tag→`!=0`/.payload 直发/NULL/UNDEF/NK_TRY 合并分支/orelse/while-unwrap/val_init/any_desc=AK_PTR）；sema 28 处基本纯语义零改动。运行时发射器四处用旧布局（zx_page_alloc/zx_heapalloc/zx_file_read/zx_format）同步改指针语义；zx_unwrap flat 版参数类型用 ctype(t)（tn 名无 typedef）。
5. **修复既有 bug**：直接 println 字符串字面量（及 typeName/file/@embedFile 等内建直发点）ZxSlice_u8 typedef 未声明 → 全部补 ensure_type。
6. 语法备忘：**switch 臂块后必须有逗号**（`.some: p { … },`），臂后无逗号报 E0202 "unexpected token in top-level declaration"（f7 排查半天其实是这个）；**匿名 fn 字面量不能当值**（`let sum = fn…` 报 "expression node reached the C emitter"，函数提模块级）。`try ?T` 要求所在函数返回 `!…`（try_thing 改 !void）。
7. 回归 251 passed / 0 failed（新增 tests/good/optflat.zx 全路径探针：orelse/switch 捕获/while-unwrap 链表求和/try/null if）。docs/manual.md 布局表加 `?*T` = 指针宽度一行，§3.9 注明唯一无标签例外。提交 06577ec。
- 顺手项未做：struct 字面量字段位内建调用、`(T)@expr` 括号两个解析毛刺。
