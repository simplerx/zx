## 三项新能力（v0.59 方向，一次提交）
1. **std/arena.zx**：ArenaAllocator（ctx 机制首个真实用户）。json 78.7→55.3ms（-30%）。坑：struct 体内嵌套命名 struct（const Block = struct）类型检查能过但 C 发射报 "expression node reached the C emitter"——类型一律提模块级。可选解包用 `if (opt) p {}`，p 直接是载荷指针；`_ = x` 丢弃不存在（E0403）；println 是变参不收 tuple（`.{x}` 会把值打印成 `{x}`）；comptime int 与 u64 比较要显式 (usize)。
2. **extern 修通**：math.h 进生成头（libc_declared 名单与实际声明此前脱节）；Zx fn 当 C 回调在 extern 调用点包 (void*)。现有 extern fn 语法 M23 就有，本次是修复不是新功能。
3. **fs 批量 + 并发**：readAll/writeAll/appendAll 转发 std.file；编译器魔法种子从只种 std 扩到每个模块作用域（sema.c module_load_full，同名声明优先）。并发安全实测：独立 FILE*，4 路 checksum 一致，2.4x 加速（16MB）。

- Zx 回调签名 fn(*const u8,*const u8)i32 与 C 的 const void* 文本不匹配是设计边界：靠 (void*) 中转，C 侧按 Zx 签名解引用。WIN32 FindData 类布局手工对齐模式见 fs.zx 顶部注释。
- 测试里 Task fn 签名是 fn(usize) !usize（错误联合），await 返回 ?usize 用 if 解包。

## FFI 补全（M24 后半）：extern struct / extern var / @link
1. **extern struct / extern union**：`const Vec3 = extern struct { … };`——类型前缀（parse_type_prefix + parse_primary 类型即值入口），is_extern 落节点、AST flg 位 2 序列化。sema `check_c_able` 逐字段校验：`?T`（带标签 optional）`[]T` `!T` 元组 方法 静态成员 默认值 全拒；`[N]T`（写作 `*[N]T`）展开成 C 内联数组 `char name[64]`（ty.c 的 ext_array_field 让 @sizeOf/@offsetOf 按内联算——普通 Zx 结构体的 *[N]T 仍是 8 字节指针，别动全局 ty_size 否则结构体拷贝按错大小 memcpy）。嵌套聚合必须也是 extern。fn 指针字段直接可用。实测 kernel32 GetLocalTime 年月日正确。
2. **@link("ws2_32")**：check_builtin 收集（zxc.c g_link_libs 去重），build_program 链接命令逐个转 -l<name>，带 / \ . 的按文件路径原样传（**手写 .o 也能挂**——混合编程验证过）。库列表盖章到 <stem>.libs，变了强制重链（.flags 盖不住链接级差异）。
3. **extern var**：`extern var g_counter: i32;`——ensure_raw 早退分支（g_fn_depth>0 拒、非 var 拒、无标注拒、有初值拒），cname 用原名（sema_sym_is_extern 扩到 NK_DECL），gen_global 发 `extern T name;` 不定义存储。**坑：backend 全局发射循环 `if (!it->b) continue;` 会把无初值的 extern var 挡掉**（已加 is_extern 旁路）；未被引用的声明不发射（惰性检查），所以纯声明测试不会产生 undefined symbol。
4. **@offsetOf** 补了 sema 侧实现（backend 早就有 case，T,T 布局在 ty_size 里顺带算好）。
5. **bootstrap 是真实前端**：zxc 的 .zx 解析走 zxfe.exe 子进程（bootstrap/lex.zx+parse.zx），改语法必须镜像过去——本次在 C parse.c 加了 case 却不生效排查了半小时才发现。AST 写端 zxfe.zx 已统一序列化 is_extern（flg 位 2），装载端 astload.c 已读，两端零改动。
6. 回归 247 passed / 0 failed（新增 exstruct/exlink/exvar 三个 good + 六个 bad）。demo/ffi/kernel32.zx 是绑定模块模式示范。
- C 侧消息如 "only extern binding"（extern const）在真实前端到不了（bootstrap 解析层就 Fail 无消息）——bad 测试别写这种 expect。
- println 不支持 `{:0>2}` 填充格式，只有 `{}`。
