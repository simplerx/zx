## M41 errdefer（v0.27）全链路落地
- 语义：与 defer 同栈 LIFO 交织，仅错误返回触发——return 按运行时 .tag != 0
  （g_saw_errdefer 门控，无 errdefer 时生成 C 逐字节不变），try 传播无条件。
  所在函数必须 !T（E0301）；体内 try/return 禁令同 defer。

  astload 通用装载无特判。
