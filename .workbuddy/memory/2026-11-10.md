## ?T 解包补全 + 命名空间三分（tools/zxls.zig, tools/lsptest.py）
- 用户截图：`var arena: ?Allocator = std.arena.ArenaAllocator.init(...)` 后
  `arena.?` 之后没有提示；"Task 命名空间污染了"。
- 根因 1：`arena.?.` 的 path 回扫不吃 `?`（recvExprStart 只认标识符/点/配平括号），
  path 变空 → 全链推断断掉。
- 根因 2：Allocator 是 sema 合成的内建类型，源文件里没有声明 → 推出
  `?Allocator` 后 containerMembersAny 落空。
- 根因 3：`arena.`（未解包）落到 inferContainer，init 返回 `?Allocator` 认不出，
  保底按接收者 ArenaAllocator 出 init/reset/deinit——全是编译错误（optional 无成员）。
- 根因 4（命名空间污染）：实例 `t.` 列出静态构造器 coro/single/pool/fromId/group
  （`t.coro()` 实测 E0303）；类型 `Task.` 列出实例字段 id（`Task.id` 实测 E0300）；
  `t.Group` 实测 E0304。
- 修法：RecvKind{module,ty,instance} + emit 过滤；recvOptionalTy 拦截 `?T` 接收者
  只提示 `?`；recvExprStart 吞 `.?`；inferContainer 认内建类型与 `.?`；
  builtinTyMembers（ctx/alloc/free 与 sema_allocator_type 对齐）；
  captureBindTy（`if (x) v {` 捕获变量按条件解包类型推）；std.heap.page 特判为值。
- 链式接收者再分：末位被调名是容器名（HashMap(i32)）→ 类型，否则 → 值
  （否则 `std.time.fromUnixMs(0).` 的 year/month/day 会被当类型过滤掉）。
- lsptest 更新为 217 项全绿（反转 staticSnippet 守门：实例无静态构造器；
  optional 用例改成 `.?` 写法；新增 gate/allocatorMembers/typePath.noField/
  genericInstField）。test.sh 全量 all checks passed（第一轮唯一 FAIL 是
  manual.md 改动导致文档站过期，重跑 tools/mksite.py 解决）。
