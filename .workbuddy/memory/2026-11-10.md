## ?T 解包补全 + 命名空间三分（tools/zxls.zig, tools/lsptest.py）
- 用户截图：`var arena: ?Allocator = std.arena.ArenaAllocator.init(...)` 后
  `arena.?` 之后没有提示；"Task 命名空间污染了"。
- 根因 1：`arena.?.` 的 path 回扫不吃 `?`（recvExprStart 只认标识符/点/配平括号），
  path 变空 → 全链推断断掉。
- 根因 2：Allocator 是 sema 合成的内建类型，源文件里没有声明 → 推出
  `?Allocator` 后 containerMembersAny 落空。
- 根因 3：`arena.`（未解包）落到 inferContainer，init 返回 `?Allocator` 认不出，
  保底按接收者 ArenaAllocator 出 init/reset/deinit——全是编译错误（optional 无成员）。
- 根因 4（命名空间污染）：实例 `t.` 列出静态构造器 coro/single/pool/fromId/group
  （`t.coro()` 实测 E0303）；类型 `Task.` 列出实例字段 id（`Task.id` 实测 E0300）；
  `t.Group` 实测 E0304。
- 修法：RecvKind{module,ty,instance} + emit 过滤；recvOptionalTy 拦截 `?T` 接收者
  只提示 `?`；recvExprStart 吞 `.?`；inferContainer 认内建类型与 `.?`；
  builtinTyMembers（ctx/alloc/free 与 sema_allocator_type 对齐）；
  captureBindTy（`if (x) v {` 捕获变量按条件解包类型推）；std.heap.page 特判为值。
- 链式接收者再分：末位被调名是容器名（HashMap(i32)）→ 类型，否则 → 值
  （否则 `std.time.fromUnixMs(0).` 的 year/month/day 会被当类型过滤掉）。
- lsptest 更新为 217 项全绿（反转 staticSnippet 守门：实例无静态构造器；

## 关联常量 / 嵌套类型 B1001 修复 + 文档目录删除（05:xx）
- 用户报的三条：① 实例补全里出现"关联函数"；② 手册/文档全丢，以后再写；
  ③ 修 struct 关联常量 B1001。
- ① 根因不是过滤失效，是**签名串味**：emit 里 `findDeclStmt(src, 名字)` 拿整份
  声明文件按名字找，`Task.spawn` 与 `Group.spawn` 同名时取到文件里第一个
  （Group 版，返回 bool），`t.spawn` 的 detail 就成了关联函数样子。
  修法：新增 `findMemberStmt(body, name)`，只在接收者容器体**顶层**找
  （depth==1，跳过嵌套 struct），emit 前算一次 `mem_body`。
  守门：lsptest `completion.instance.sameNameMember`（spawn 必须是
  `spawn(f: fn (usize) !usize, ctx: usize) ?usize`，且 coro/single/pool/
  fromId/group 不得出现）。std 里同名成员共 8 组（close/deinit/grow/init/
  next/open/push/spawn），全部受益。
- ③ 关联常量 `const K: i32 = 7`：`O.K` 走 TY_TYPE 分支能 ct_eval 折成 7，
  实例 `c.K` 只返回类型 → 后端照字段发 `c.K` → B1001。修法：sema 里
  `static_member_ty()`（is_static && !is_var && dflt → ct_eval_probe 折值，
  val_cast 到声明类型），TY_PTR/TY_STRUCT/TY_UNION 三处都走它。
- 顺带两个同族坑：`const Inner = struct {…}` 静态**类型**成员被后端物化成
  C 变量（ctype(TY_TYPE)=void、初值是类型节点 → E0300+B1003）→ 物化时跳过
  TY_TYPE；`O.Inner{…}` 构造拿不到 type_val → 类型分支里把 dflt->type_val
  挂到 n->type_val。静态切片常量 `const NAME: []const u8 = "…"` 物化成
  `(uint8_t*)"…"` 不合法 → 显式发 `((ZxSlice_u8){ptr,len})`（cstr 前置声明）。
- 守门：tests/good/assoc-const.zx（类型取/实例取/编译期数组长度/嵌套类型构造
